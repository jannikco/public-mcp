# Changelog

## 1.0.0

Initial Public MCP setup package for HeyMyApps: authenticated gateway discovery and stdio bridge for connector `public`, `heymyapps-public` agent skill, 25 default read tools and four trading tools documented from [Public OpenAPI](https://github.com/PublicDotCom/public-openapi/blob/main/spec.yaml). Trading tools are off by default; hosted approvals are required for order placement. `HEYMYAPPS_*` env vars are primary with `PIPMCP_*` aliases.
